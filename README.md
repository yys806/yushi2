# 珅玉定制 APP

《珅玉定制》是《中国玉石与玉文化鉴赏》课程「Ai 时代玉器的传承与创新」任务作品。项目以玉石文化传播为核心，结合生成式 AI 提供玉器定制、评级与展示能力，包含用户前台与管理员后台两套系统。

## 设计初衷

在课程学习过程中，我希望通过 AI 技术降低玉文化体验门槛：

- 用生成式模型让用户直接参与玉器创意设计。
- 用玉苑图文内容展示天然玉石与玉雕作品，提升认知与兴趣。
- 用可运营后台支持公告、活动、额度审批、内容更新，实现长期维护。

## 系统架构

### 前端

- 技术栈：React + Vite
- 部署：Netlify
- 说明：面向用户提供注册登录、定制、生成、玉苑浏览、个人中心等完整流程。

### 后端

- 平台：Supabase（数据库 + Edge Functions + Auth）
- 说明：负责用户数据、玉苑数据、配额/审批/公告活动等业务，以及 AI 调用链路。

### AI 能力链路

- DeepSeek：生成设计方案与评级说明
- Qwen-Image：根据方案生成玉器成品图
- 业务流程：参数输入 -> 方案生成 -> 成品生图 -> AI 评级 -> 收藏/历史沉淀

## 前端功能模块

### 1) 登录界面

- 邮箱注册与登录
- 注册信息校验（邮箱/昵称唯一、密码规则）
- 登录后进入主流程页面

### 2) 首页

- Logo 与应用标题展示
- 玉石/玉雕轮播图（支持后台配置）
- 推荐模板（猜你想做）一键套用
- 课程作业说明信息展示

### 3) 定制界面

- 材质、纹饰、样式选择
- 模板中心一键填充参数
- 预算、赠送对象、自定义要求输入
- 一键发起成品生成

### 4) 成品界面

- 三阶段生成进度反馈
- 成品卡片展示（图片、方案、亮点）
- AI 评级与说明
- 收藏、重新编辑、保存下载

### 5) 玉苑界面

- 天然玉石与玉雕作品浏览
- 关键词搜索（玉石名、玉雕名、玉雕大师）
- 卡片详情与大图查看

### 6) 我的页面

- 账户信息与剩余额度
- 昵称/密码修改与退出登录
- 额度申请、历史记录、收藏管理
- 消息通知与审批状态查看

## 管理后台功能模块

### 1) 事项审批

- 审批用户额度申请
- 支持通过/拒绝与备注

### 2) 用户管理

- 查看用户信息、已用额度、剩余额度
- 调整用户额度与删除用户

### 3) 公告发布与活动发布

- 面向全体或指定用户推送公告
- 发布活动额度奖励并指定对象

### 4) 评级概率配置

- 调整各评级卡片出现概率
- 支持运营侧玩法优化

### 5) 玉苑管理

- 首页轮播图管理（最多 6 张）
- 玉苑图片上传与内容维护

## 本地开发

```bash
npm install
npm run dev
```

常用脚本（以 `package.json` 实际内容为准）：

- `npm run dev`：启动前端开发环境
- `npm run build`：构建前端产物
- `npm run preview`：本地预览构建结果
